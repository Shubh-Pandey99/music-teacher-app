## ✨ Features

- 🗓️ **Attendance Management** — Mark and track daily student attendance with a clean, dynamic calendar UI.
- 👨‍🎓 **Student Profiles** — Comprehensive individual student records displaying performance history, session notes, and long-term progress.
- 📊 **Analytics Dashboard** — Visual insights into attendance trends, performance metrics, and class-wide statistics utilizing modern charting libraries.
- 📋 **Session Notes** — Write, edit, and organize per-session notes and lesson progress for each student.
- 🔐 **Secure Auth** — Robust, session-based teacher authentication and protected student data views.
